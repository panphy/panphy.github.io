Why PanPhy

About

Small, useful physics apps that run wherever a browser does.

Browser based Classroom friendly Offline ready

Welcome to PanPhy Labs. These tools, simulations, and games are built with AI and designed to be interactive and educational. When existing web tools do not quite fit the job, I build my own: focused, approachable, and ready to use without installing software.

Most apps are offline-friendly after the first visit. Look for the Offline ready badge on each card. Games and features that rely on external services still require an internet connection.
