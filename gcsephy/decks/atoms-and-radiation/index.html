Radioactive decay.

  • Activity: decays per second, in becquerel (Bq)

Half-life

Half-life.

  • Time for the number of unstable nuclei to halve
  • Or: time for the count rate (activity) to halve
  • Same time for every halving
Iodine-131: half-life ≈ 8 days
DECAY CURVE · IODINE-131
ATOMS & NUCLEAR RADIATION

Half-life

Using half-life.

From a graph

Find the half-life

  • Read the start value
  • Halve it
  • Read across, then down
  • 400 → 200 at 8 days

Count the halvings

T½ = 8 days · 24 days?

  • 24 ÷ 8 = 3 half-lives
  • 400 → 200 → 100 → 50

As a ratio HT

Net decline

  • Left after n half-lives: (½)ⁿ
  • 3 half-lives: ⅛ left
  • Net decline: ⅞
