# Lesson 6: Paper Helicopter Independent Skills Challenge

## Unit
Working Like a Physicist: Collecting, Processing, and Presenting Data

## Lesson focus
Students independently apply the data handling skills developed across the unit: variables, tables, repeated measurements, averages, graph choice, plotting, best-fit lines, and outliers.

## Assumptions
Students have already practiced categoric data, continuous data, bar charts, line graphs, and best-fit lines.

## Practical title
Paper helicopter investigation

## Recommended investigation question
How does wing length affect the fall time of a paper helicopter?

## Why this practical works well
This practical is fun, cheap, and easy to run in a standard classroom or lab. It gives students a chance to design a table, collect repeated results, calculate averages, choose a graph, and plot a line graph.

## Learning objectives
By the end of the lesson, students should be able to independently:

1. Identify independent, dependent, and control variables.
2. Draw a suitable results table.
3. Collect at least 3 trials for each value of the independent variable.
4. Calculate mean values.
5. Choose the correct graph type.
6. Plot a line graph accurately.
7. Draw a best-fit line.
8. Identify possible outliers.
9. Write a conclusion based on the data.

## Key vocabulary

| Keyword | Student-friendly definition |
|---|---|
| Independent variable | The thing you change |
| Dependent variable | The thing you measure |
| Control variable | Something you keep the same |
| Continuous data | Number data that can have many possible values |
| Mean | The average value |
| Best-fit line | A line that shows the overall pattern of the results |
| Outlier | A result that does not fit the pattern |

## Equipment
Per group:

- Paper helicopter templates
- Scissors
- Paperclips
- Stopwatch
- Meter ruler
- Graph paper
- Exercise book or investigation sheet

## Safety notes

- Students should not climb on chairs or benches to increase drop height.
- Use a sensible drop height that can be reached safely.
- Scissors should be used carefully.
- Students should stand clear of the drop zone.

## Alternative investigation options

Students could investigate one of the following:

1. How does wing length affect fall time?
2. How does paperclip mass affect fall time?
3. How does drop height affect fall time?

Recommended option:

> How does wing length affect the fall time of a paper helicopter?

This is recommended because wing length is continuous and leads naturally to a line graph.

## Suggested independent variable values

Students can test 5 different wing lengths, for example:

- 4 cm
- 5 cm
- 6 cm
- 7 cm
- 8 cm

## Method

1. Make a paper helicopter with the chosen wing length.
2. Add the same number of paperclips each time.
3. Drop the helicopter from the same height.
4. Measure the time taken to reach the floor.
5. Repeat 3 times for the same wing length.
6. Calculate the mean fall time.
7. Repeat for the other wing lengths.
8. Plot a line graph of wing length against mean fall time.

## Final assessed task

Students produce one page containing:

1. Investigation question.
2. Variables.
3. Results table.
4. Mean values.
5. Correct graph.
6. Best-fit line.
7. Comment on outliers or errors.
8. Conclusion.

## Success criteria

| Skill | Success criteria |
|---|---|
| Variables | Independent, dependent, and control variables identified correctly |
| Table | Units, trials, and mean column included |
| Repeats | At least 3 trials for each wing length |
| Graph choice | Line graph chosen because wing length is continuous |
| Graph quality | Axes labeled, units included, sensible scale used |
| Best-fit line | Best-fit line drawn instead of dot-to-dot line |
| Outliers | Possible outlier identified or absence of outliers stated |
| Conclusion | Conclusion uses evidence from the results |

## Possible prep

Students write a short evaluation of their investigation, including:

1. One strength of their method.
2. One weakness of their method.
3. One possible random error.
4. One improvement they would make next time.

## Teacher notes

This lesson can be used as a light-touch assessment of the whole unit. Students who are less confident may need a scaffolded results table, while more confident students can design their own table and choose their own wing lengths.
