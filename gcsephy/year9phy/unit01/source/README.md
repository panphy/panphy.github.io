# Editable source archive

Preserves the original Sites/React student companion source and its Git history. Dependency folders, build output and previews are excluded. The live site is maintained directly in `../index.html`, `../lesson/` and `../assets/`; edit those for ordinary changes.

- `student-companion-site/`: original source at commit `e76297a` (seven lessons, 28 questions). See its README.
- `student-companion-site-history.bundle`: backup of the four-commit history. Restore with `git clone student-companion-site-history.bundle restored-student-companion-site`.
