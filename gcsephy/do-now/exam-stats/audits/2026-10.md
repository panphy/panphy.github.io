# Audit, October 2026

**Data audited:** 24 Higher papers, November 2020 to June 2025 (838 parts, 2,040 marks).
**Auditor:** ChatGPT, given the prompt that `audit-prompt.py` is based on, the public CSV files and links to the papers. It reported reading all 24 question papers and 24 mark schemes.
**Outcome:** every headline figure reproduced; no transcription mismatch in 48 sampled parts (two from each paper); nine findings, all acted on in pull request 924.

| Finding | What was done |
|---|---|
| A mark scheme gives June 2024 Trilogy Paper 2, part 03.7, an electromagnetism reference, but the question is about radio waves | Counted under electromagnetic waves through `corrections.csv` |
| "Recall" claimed more than AO1 shows, and the full equations sheet was not provided in 2020 and 2021 | Method slide and README reworded |
| AQA discounted Question 11 of June 2022 Physics Paper 1 (confirmed in the examiner report) | Marked `Discounted` in `corrections.csv`; still counted as printed, with a footnote |
| `facts.csv` had no question references; one entry was unsupported and two occurrences were missing | Rebuilt with one row per occurrence (series, paper, part); entry removed, two added |
| The README said marks are shared equally between assessment objectives, which is not what the data does | `Recall` definition corrected |
| Section 4.3.3 was mapped to a Separate-only topic | Mapped to the shared gas topic, with rows for 4.3.3.2 and 4.3.3.3 |
| Four topic names were narrower than the sections they collect; 4.3.2.2 sat under Internal energy | Topics renamed; 4.3.2.2 moved to specific heat capacity, which moved two Target 7 bands |
| "Writing down an equation" also covered multiple-choice selections | Relabelled "writing down or choosing" |
| Combined and Separate topics were ranked together on different denominators | One view per course (pull request 925) |

**Not covered:** the audit sampled 48 of 838 rows, so the record is not fully verified. It did not notice the three parts typed in by hand (June 2024 Trilogy Paper 1, parts 02.2, 03.5 and 03.6).

**Worth repeating next time:** ask for content checks as well as transcription checks (that is how the radio-wave reference was found), and ask for the examiner reports to be read (that is how the discounted question was found). Both are now in the prompt.
