# PanPhyCircuits

A circuit builder and simulator for GCSE and IB Physics. Entry point: `tools/panphycircuits.html`, listed under Tools on the homepage. Plain HTML, CSS and classic scripts; no build step. It works offline: every file here is in `ASSETS_TO_CACHE` in `sw.js` and in the page's offline requirements in `index.html`, so add new files to both and bump `BUILD_ID`.

## Structure

| File | Role |
| --- | --- |
| `js/units.js` | SI formatting and parsing (`4.7k`, `100 µF`) |
| `js/registry.js` | Component types: terminals, properties, electrical models, readings, help text |
| `js/circuit.js` | The document: components, wires between named terminals, nets, import validation |
| `js/solver.js` | MNA solver (Newton–Raphson, ideal-source loop analysis, BDF2 capacitor/inductor transients, logic settling) and the fixed-step simulation engine |
| `js/art-common.js`, `art-realistic.js`, `art-schematic.js` | Original SVG artwork per type, with terminal coordinates for each view |
| `js/layout.js` | Per-view geometry: transforms, wire routing, junction splitting, layout generation and syncing, Tidy up |
| `js/render.js`, `editor.js`, `ui.js`, `graph.js`, `app.js` | Workspace rendering, interaction, panels, graph, state/history/autosave |
| `js/audio.js` | AC-frequency sine tones, with volume from smoothed AC current |
| `js/examples.js` | Example circuits, each with a realistic layout and a circuit diagram |

Adding a component: define it in `registry.js` (terminals, props, `compile` into solver primitives, `readings`), then add an entry with `bounds`, `terms` and `draw` in both artwork files. Terminal ids must match in all three; `tests/model.test.cjs` checks this.

## Key design points

- Selected components and wires show a small upper-left × button that deletes only that object (undoable). Right-click or touch and hold a component for compact property fields and numeric sliders with the same units, limits and settings as the inspector; Escape or a click outside closes them. Settings open outside the component and its delete button, choosing a nearby side with room on screen; tall menus scroll when needed. If zoom leaves no room, a message asks you to zoom out. Moving cancels the touch hold so dragging stays immediate; terminals and momentary push buttons keep their direct controls. Right-click still cancels wiring, and dragging empty space with the right button still pans.
- One shared electrical circuit; each view stores its own positions, rotations and wire bends. Connectivity is explicit (wire ends name a component terminal), never inferred from geometry. Circuit diagram wires automatically reroute when saved bends would double back over leads, pass through symbols or other terminals, overlap other wires (wires from one terminal may run together and split at a dotted T), touch unrelated wire ends or corners, or cross or touch their own earlier segments after an edit. Automatic lead extensions shrink to fit clear space near terminals. Diagram moves stop before symbols overlap, for both dragging and arrow keys. Valid saved bends are retained; rendering never changes electrical connections or the other view.
- Networks are solved separately, each with its own reference node, so a p.d. between unconnected circuits is undefined. Loops of zero-resistance elements are found before solving: a non-zero EMF is reported as a short circuit or conflict; a zero EMF leaves the currents around the loop undefined (shown as “?”).
- Circuits run live by default, including examples, opened files and autosave. The solver finds the steady state after each edit; time advances only for capacitors, inductors, AC supplies, scopes and plotted meter graphs (`app.needsTime`). Use a circuit switch to trigger an effect. Pause/Resume appears at the bottom right when time matters; an explicit pause survives edits and removal of time-dependent parts. Pause freezes time, current/component animations, traces and sound; edits still update readings at the frozen state. The Simulation inspector has a plain live/paused status row and a labeled Pause/Resume button, synchronized with the canvas pill. Switching views fits the circuit into the canvas and never touches simulation state. Saved files hold the circuit, not live state.
- Inductors are Extensions with editable inductance, optional winding resistance and signed initial current. They use backward Euler after edits or time-step changes, then BDF2. Current history survives edits and pause; opening a saved circuit restores the initial current. Automatic steps consider L/R decay and LC oscillation scales.
- The last autosaved circuit opens directly and live. Unsupported parts and their connected wires are skipped on file import or autosave restoration, with a warning; the remaining circuit is retained. Clear circuit removes it (undoable) and returns to live operation. Saved empty circuits also keep their settings and camera. The empty-canvas start card offers a clean canvas, which just dismisses it.
- Fast AC current animation replays a sampled cycle at 1 visual Hz, independently for each single-frequency electrical network. Samples come from the actual solver, so rectifiers keep one-way flow and DC offsets/phase shifts are retained. The cycle is refreshed after a 0.25 s simulation-time gap; edits discard old samples. Low-frequency AC (including slowed simulation), mixed-frequency networks and manual time steps with fewer than 16 samples per cycle keep live flow. A canvas note labels slowed animation; meters, scope traces and audio retain actual frequency. Pause freezes the visual phase and dash displacement too.
- AC supplies and oscilloscopes are Core physics components. Yellow is reserved for current-flow animation, so the wire palette omits it. Examples use purple signal/AC wires; old yellow wires are converted to purple on import or copy.
- Display choices (labels, values, current animation, wire colors and logic symbols) are saved immediately in browser storage (`panphy-circuits-display-v1`), separately from the circuit autosave. They carry across reloads, clean canvases, examples and opened files, overriding the file's display settings once a preference is saved. Simulation speed and time step stay with the circuit. Colored diagram wires adapt black and white to contrasting gray tones in dark and light themes respectively; SVG/PNG exports keep those displayed colors.
- The layout follows the suite shell of PanPhyPlot, PanPhyMD and PanPhyTrack: an app bar with a spectrum line, three panes on graph paper (Components, Circuit, and the inspector as a column of PanPhyPlot-style cards), and one status bar with the copyright. The view toggle sits in the Circuit pane's heading and the tools in its toolbar row. The live/paused state and investigation controls sit in a chip at the bottom right of the canvas; the Display settings icon (labels, values, current animation, wire colors, logic symbols) and Clear sit together at the right end of the toolbar. Below 900 px Components and the inspector slide in over the circuit; a left-pane button beside the view toggle and a right-pane button at the far right of the same heading bar toggle them, with highlighted open states and Show/Hide labels.
- Files are saved as `.ppcir` (the same JSON document; `format` stays `"panphy-circuits"`). Open also accepts `.json` files from earlier versions. iPhone and iPad get an unfiltered file picker because they grey out unknown extensions.
- File → Export to PanPhyMD opens a new tab with the current view embedded as an SVG data URI. The handoff uses the URL fragment, like PanPhyTrack → PanPhyPlot, and appends the image to any saved PanPhyMD draft. The image keeps the current theme and readings and needs no external image file.
- Tidy up (`layout.tidy`) works on the current view only and never changes a connection. It always fits the circuit into view afterward, even if the layout is already tidy. It has a time budget of about 2.5 s, and repeats its search within that budget until it stops improving, so a second click normally finds nothing more to do. Circuits built from two-terminal parts and single-channel scope branches in series and parallel (`layout.seriesParallel`) get the textbook layout (`layoutSeriesParallel`): each circuit a rectangle with its source centered on top and the rest along the bottom with equal gaps (in a series loop of three or more, the end parts stand on the sides; on the bench only parts with a lead at each end do, and meters and AC/DC supply boxes are never turned on the bench, nor the oscilloscope in either view), parallel branches stacked between rails in the order their wires join them (meters below when that draws as cleanly), each junction part at the point of its net nearest the ends it is wired to, separate circuits side by side, and wires given bends at the drawing's corners. Scopes use only their connected terminals for this layout; their unused channel remains reserved by routing. In the diagram the textbook layout is judged by its rendered routes; if they still have defects, the local search below also runs and the drawing with fewer defects is kept. Anything else (other three-terminal parts, dual-channel scopes, bridges, loose ends) uses a local search over moves, turns, mirrors and swaps scored by `layout.tidyCost`, then spreads small circuits to a minimum size, lines up and spaces runs (`distributeRuns`) and separates overlaps.
- Clean schematic rows and branches are preserved, including the symmetric AND inputs and the diamond bridge. Logic symbols, inputs, outputs and supply rails stay upright in the diagram. The final schematic check scores the actual rendered routes, including wire avoidance, and rejects extra crossings, obstructions or unnecessary bends/detours even when independent-route estimates improve. Invalid saved bends can be repaired without moving parts; this safe repair is kept if the search would worsen the drawing. A tidy that would leave more overlaps, crossings or wires over parts keeps the original layout.
- The full-wave bridge example follows the diamond layout: AC across the top/bottom vertices, load across the right/left outputs. Scope CH1 and COM connect only across the load; CH2 is unused because the AC input and rectified output do not share a reference terminal.
- Opening the graph switches on “Plot on graph” for the selected meters, or for every meter when none is selected and none is plotted yet.
- Text that changes while the app runs (run state, time, graph legend values, problems count) and the view toggle (two equal halves) sits in fixed-width boxes so nothing shifts; keep it that way when adding live readouts.
- A fuse blows in `blowFuses` (app.js) after any solve that puts more than its rating through it; it stays blown (saved with the circuit, not undone) until “Blown” is switched off. The motor's rotor and the loudspeaker's cone animate with CSS, and freeze during an explicit pause; the loudspeaker plays a sine tone at the frequency of an AC supply in its own electrical network while time runs. Volume follows the smoothed changing current; steady DC, open circuits and inputs below 20 Hz are silent. Play sound mutes an individual speaker. Simulation speed does not change the pitch. Multiple supply frequencies in one network share the current envelope across their tones; this is a simple frequency-and-volume model, not full waveform playback or a speaker-acoustics model. Audio starts after a browser gesture, stops when the page is hidden, and works offline without downloaded media. Older files load with tones; a saved music Off setting remains muted.
- Junction dots in the circuit diagram require an explicit shared terminal with three or more drawn line directions, counting part leads, or mark where wires from one shared terminal run together and then split. Incidental wire crossings, corner contacts and nearby unconnected terminals never create dots. A selected ammeter, voltmeter, ohmmeter or oscilloscope shows its display large in the inspector, above its readings: the meter's own bench artwork (so it looks like the part) or the scope screen. Pin keeps a display at the top of the inspector while other parts are selected, in a separately scrollable area capped at 45% of the inspector height so readings and controls remain accessible (`app.pinned`, not saved; `ui.renderLive`). The handle below that area (drag, arrow keys, or double-click to reset) sets its maximum height instead, kept in `localStorage` and limited so the inspector's own cards keep at least 120 px. The thermistor's and LDR's bench badges are sliders: drag across them to set temperature or illumination (an `upright` slider actuator that stays horizontal however the part is turned).
- A newly placed part moves to the nearest clear spot (`layout.clearSpot`): clear of other parts in both views, and clear of wires in Realistic view, whose curved wires do not steer around parts. Parts you drag stay where you put them.
- The ohmmeter (an extension) is a 1 V test source behind 1 kΩ, so its test current is at most 1 mA; it shows R = V ÷ I and OL above 100 MΩ or on an open circuit. Like a real meter it misreads a powered circuit, and lamps and diodes read their resistance at that small current.
- Mirror (toolbar, selection panel or M) flips the selected parts left to right on screen at any rotation (`layout.mirror`). Labels, values and printed text stay readable; parts that cannot rotate cannot be mirrored.
- AC/DC supply boxes stay upright in Realistic view, including manual rotation, imported circuits, generated views and Tidy up. Their schematic symbols can rotate.
- DC and AC supplies have a draggable voltage slider on the bench front panel (0–30 V in 0.5 V steps). Their inspector keeps precise numeric entry alongside voltage sliders and a logarithmic AC frequency slider (1 Hz–1 kHz).
- Each oscilloscope display has an Auto scale toggle for the vertical axis only, enabled by default for new scopes. Each channel fits the visible sample window using 1–2–5 volts/div steps with headroom; the inspector, pinned displays and both workspace views share the calculation. Turning Auto scale off restores the saved manual volts/div settings. Auto time base is separate and defaults on: it chooses a 1–2–5 time/div that shows a few periods of AC supplies connected to that scope, independently of other networks. Turn it off to use the saved manual time/div (100 µs/div to 5 s/div). Scope traces start afresh after circuit/source changes. Scope channels use bounded trace buffers; AC cycle-averaging windows are reserved for meters so dense multi-scope acquisitions do not duplicate those buffers. Long acquisitions and all three displays retain actual sample extrema instead of striding samples, so dense signals keep their peak envelope without false alias waveforms.
- The Guide uses expandable topics, with Start building open initially, a fixed close/header row and a scrolling reading area. Keep instructions in the relevant topic instead of adding dense columns.
- The core Transformer has four isolated terminals and independent primary/secondary turns controls (10–2000 whole turns). Its coupled-inductor model uses 99.9% coupling, 10 H and 0.1 Ω per 100-turn winding, both scaled with turns squared. AC voltage follows the turns ratio approximately; secondary loading reflects into the primary. DC produces a transient that decays, with potentially large primary current. Each galvanic island keeps its own voltage reference even when coils are solved together. Transformer current history follows the inductor pause/edit/reset lifecycle. Core loss and saturation are not modeled.
- Model notes for each component are shown in its inspector.
- The library opens on Core physics until a filter is chosen; the last choice is remembered in this browser (`panphy-circuits-library-filter-v1`). A search looks through every part whatever the filter. Meters wired so they cannot measure (a loose lead, a voltmeter with both leads on one point, or an ohmmeter on a powered circuit) glow orange and get a note in the problems list and in their Readings card (`app.meterNotes`).
- The Pause control in the canvas corner appears only when time matters; otherwise the corner shows a plain Live label whose tooltip explains why.

## Tests

```sh
node --test tools/panphycircuits/tests/*.test.cjs
```

`solver.test.cjs` compares the solver with hand calculations (series/parallel, bridge, switches, polarity, shorts, conflicting sources, RC/RL against the exponential, LC energy exchange, AC inductor phase lag, transformer turns ratios/loading/isolation/DC decay, diode, LED, lamp, transistors, every gate truth table, latch, AC r.m.s., ohmmeter readings). `model.test.cjs` covers terminal mapping, rotation (including 45° steps), mirroring, clear placement of new parts, junction splitting, view sync, diagram rerouting after component moves, terminal and corner clearance, self-crossing rejection, a sweep of 1,569 valid lamp positions including narrow lead gaps, genuine junction dots, full oscilloscope frame clearance, single-channel scope fast layouts, symbol collision checks, examples and import safety. It also checks repeated Tidy on the clean AND diagram, rendered-route quality, straight leads/positive readings in the parallel-resistor example, textbook Tidy of branches wired straight onto terminals (shared trunks and their dots), separate junction points, and Tidy's time limit and second-click stability. `scope-scale.test.cjs` covers automatic voltage/time scaling, manual restoration, saved settings, 44 Hz sine acquisition, peak-preserving reduction, bounded long acquisitions, three-scope tiny-step RLC acquisition past the first AC cycle, separate meter averaging, and clearing traces after source edits. `audio.test.cjs` checks supply-matched frequency, current-controlled volume, network isolation, sub-audible/DC silence, saved mute compatibility and audio lifecycle with the real solver. `flow.test.cjs` checks slow AC replay against actual solver currents, rectification, DC isolation, pause, source edits and live fallbacks. `editor.test.cjs` checks touch/pen holds, short taps, drag cancellation, switch controls, momentary buttons, terminal wiring, pinch and pointer cancellation, native context menus, mouse input and stale documents. All run on every pull request (`.github/workflows/checks.yml`).

## Requirement checklist

Done: both views fully editable and synchronized; Tidy up and Clear circuit; core components (including transformer, fuse, motor, loudspeaker, AC supply and oscilloscope) and the extensions (capacitors, inductors, NPN/PNP, seven gates, logic I/O and rails, two-way switch, ohmmeter); wiring with bends, junctions, reconnecting ends and crossing hops; undo/redo; meters and inspector readings; graph; 9 examples; automatic restoration of the last autosaved circuit, .ppcir import/export, SVG/PNG export; light/dark themes; keyboard shortcuts; tablet layout.

Not done / limitations: no thermal lag in lamps, no reverse breakdown, no magnetic saturation or coupling between separate inductors, no transistor Early effect or capacitance, no gate propagation delay; logic modules share one hidden 5 V supply; phone-width layout works but is cramped.
