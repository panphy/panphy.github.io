# PanPhyTrack manual screenshots

Five light/dark WebP pairs (captured as PNG, saved at quality 90) illustrate the walkthrough in `../manual.html`. `manual.css` uses the shared Spectrum tokens from `/assets/design.css`; `manual.js` manages Contents, theme-aware screenshot zoom and focus restoration. Capture the real app with **Try a sample** in an isolated browser session.

Filenames stay stable. When replacing a pair, update dimensions and captions in the manual if needed. List images in `sw.js` and the PanPhyTrack `OFFLINE_CARD_REQUIREMENTS` in `index.html`, then bump `BUILD_ID`.
