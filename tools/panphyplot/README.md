# PanPhyPlot

PanPhyPlot is a column-based graphing and fitting workspace for tablets and computers at `tools/panphyplot.html`, available offline through the root service worker. Small screens show a laptop/tablet recommendation with Continue and Not now choices; Continue opens this same workspace. Not now returns to the homepage.

Saved trial work continues under `panphyplot-neo-state-v1`, with no migration or deletion. Pane widths and tour-seen preferences also keep their original storage keys. All tabs share the workspace: a tab pauses saving when another tab saves, and offers to reload or keep its own version. The one-time original-data offer reads `panphyplot-state-v2`, appends nonempty datasets as new sheets, and records acceptance or decline atomically with the workspace. Draft cell text, names, units, titles, and absolute/percentage uncertainties are preserved; disabled uncertainty columns import as Ignore. The complete original save stays untouched. The introductory PanPhyPlotOG copies its previously active dataset into a separate save and restores basic fits only. Neither app writes the other's storage key.

File → Save downloads a complete `.ppplot` project (versioned JSON): all sheets, draft cell text, formulas, graph titles and zoom ranges, hidden series, fitted curves and results, fit models and extensions, custom bounds, equation symbols and current fit controls. File → Open validates it before asking to replace the current sheets; invalid files and storage failures leave the current project intact. CSV Import/Export remains for one sheet of values.

Each tab is a sheet of columns. A column's role is X, Y, ±ΔX or ±ΔY (absolute or %), or Ignore. Pairing follows Origin: a Y column plots against the nearest X column to its left, a ΔY column belongs to the nearest Y to its left and a ΔX column to the nearest X. Axis titles are built from names and units as `name / unit`.

A formula column (such as `T^2` or `mean(B, C, D)`) is recalculated from its sheet whenever the data changes. Formulas refer to columns by letter, or by name when the name is a valid, unique identifier, and letters are rewritten when columns move or are deleted. A row with a blank or invalid input stays blank. Mean of Repeats adds such a column, plus an optional ±Δ column of half the spread between the largest and smallest readings. A formula column can also have a ±Δ column that carries the uncertainties through: Δf = √Σ(∂f/∂x · Δx)², using each input's own ±Δ column (by the pairing rule), with the derivatives taken numerically and shown symbolically in the formula dialog.

Weight by uncertainties weights every fit type by 1/σ², with σ² = ΔY² + (f′(x)·ΔX)², re-weighted as the fit settles. Every fit reports its parameters as value ± uncertainty using the equation’s selected decimal places (scientific notation preserves small nonzero values). Uncertainties come from the covariance matrix: with weights, σ is taken as a standard uncertainty; without, the uncertainty comes from the scatter. χ²/ν is shown when every point has a ±ΔY or ±ΔX. In formulas, `mean`, `median`, `min`, `max` and `halfspread` leave out blank readings among their inputs, and renaming a column rewrites the formulas that use its name.

The Result card’s collapsible Equation symbols fields set display-only notation for the paired columns, independently of their names and units. Symbols persist with each column; blank fields use a one-letter column name or fall back to x/y. Simple LaTeX supports Greek letters, subscripts and powers, with live previews and validation. The copied equation uses the same notation. Custom fit formulas still use `x`.

CSV import shows a preview in which every column's role is chosen; the suggested roles come only from clear headings. CSV export writes `name / unit` headings, which import reads back. Motion Tracker's Export to PanPhyPlot opens `panphyplot.html#import=<JSON>`; `importLinkedData` in `js/ui.js` puts the columns (names, units, roles, hidden series) into an empty or new sheet and clears the hash. The data travels in the link, not in storage, so it also reaches a tab with separate storage.

- `js/model.js`: the column model and formula engine, pure and testable in node.
- `js/stats.js`: weighted straight lines, parameter uncertainties and χ², also pure.
- `js/project.js`: versioned project validation, model restoration and the Open/Save controls. Files contain data and settings; graphs are rebuilt, and no saved JavaScript or HTML is executed.
- `js/legacy-import.js`: pure conversion of original datasets into sheets.
- `js/state.js`: saved state, and the globals the fitting code reads. Fits are keyed `<sheet id>:<Y column id>`. How far each fit line extends beyond its data is saved in `extents`; curves also keep full-precision model descriptions so their evaluation functions can be restored after reloading or opening a project. Older saved fits without a recoverable model remain visible but may need fitting again before extending.
- `js/fit-core.js`: shared numerical routines, copied identically to PanPhyPlotOG. Built-in nonlinear fits use scaled coordinates and variable projection: QR solves the linear coefficients while the search refines frequency/damping, Gaussian centre/log-width, exponential rate, or power-law shift/exponent. For at least 128 near-uniform samples, a zero-padded FFT supplies frequency starts, including rounded Sound Analyzer timestamps; every candidate and refinement still uses every original x-y point. Other grids retain the frequency scan. Sinusoidal profiles use allocation-light, reorthogonalized QR with a bounded cache. Automatic searches stop at the uniform-grid Nyquist limit (median-spacing limit for irregular samples); a larger manual frequency extends the search. This cannot remove sampling ambiguity. Gaussian starts handle signed peaks and nonzero baselines; power-law refinement keeps its base positive.
- `js/fitting.js`: fits the selected Y series and records its source data. `finalizeParametricFit` applies requested effective-variance weighting and calculates parameter uncertainties. Exponential amplitude is reported at the fixed reference x shown in its equation. Custom formulas use expression-aware scales, multiple starts, optional saved Min/Max bounds, and a direct QR solution when symbolic derivatives show linearity in the parameters. Worker and fallback paths use the same core. Advanced guesses are calculated when their tab is visible, reused for unchanged data, and sent to the worker for 128 or more points; stale replies cannot overwrite edits or another series. Sinusoidal lines use up to 3,000 samples to draw many cycles clearly. OG exposes only basic fits; keep numerical-core fixes in step manually.
- `js/plot.js`, `js/ui.js`, `js/dialogs.js`, `js/main.js`: graph, table, the formula, mean and CSV dialogs, and start-up. Sheets above 200 rows render a visible window with spacers; keyboard navigation brings target rows into view, while selection, copying, formulas, fitting and export read the complete model. CSV import renders the new sheet once.
- `js/copy.js`: View Table (copy for a spreadsheet, as an image, Markdown or LaTeX) and copying the fitted equation as an image or LaTeX. Its clipboard and SVG-to-PNG helpers are independent of the introductory OG app.
- `js/tour.js`: the guided tour at `?tour=columns`, from repeat readings to weighted fits, equation symbols and project saving, on practice data with saving switched off. Its card and spotlight engine is copied from `misc/panphyplotog/js/tour.js` and uses `tools/panphyplot/css/tour.css`.
- `js/panes.js`: the draggable dividers between panes (from 1000px), on the PanPhyMD model. They snap onto their starting positions within 16px, and widths are kept per layout under `panphyplot-neo-panes` in this browser. Column widths are saved with each column.
- `manual.html`: the manual for this version.

Each app owns separate copies of `fit-core.js`, math.js, `math_ref.html` and `tour.css`; keep necessary solver fixes in step manually. PanPhyPlot also owns its fit worker, advanced/custom fitting and mathematical rendering; it loads no OG scripts. The page and support resources in this folder are precached. The internal `neo-` CSS/DOM prefixes remain to avoid changing layout selectors. Everything else is styled by `css/panphyplot.css`: an app shell with a toolbar, data, graph and inspector panes, and a status bar. Its layout has three panes from 1280px, data beside a scrolling graph-and-cards column from 1000px (the tour's `TOUR_NARROW_WIDTH`), and one column below that.

Automatic-start regressions cover shifted/signed Gaussian peaks, sine aliases and damping, unit changes, exponential translation, power-law domains, custom bounds and linear custom formulas. Run the tests with `node --test tools/panphyplot/tests/*.test.cjs misc/panphyplotog/tests/regression.test.cjs`.
