Start here

Write your first formula

  1. Choose Data → Formula in the app’s toolbar.
  2. Use a column letter, such as B^2, or a unique column name, such as T^2. No leading = is needed.
  3. Check the result preview, give the new column a name and unit, then choose Apply.
Reading the examples

A and B below mean column A and column B in the same row. Replace them with the letters or names in your own sheet. Formula columns update when the source data changes.

Operators

Write multiplication explicitly with *, and use parentheses to control the order of calculation.

Arithmetic operators and examples
Operator Meaning Example

Transform a reading

Functions

Put the input inside parentheses: sqrt(B) takes the square root of each value in column B.

Trigonometry

Angles are in radians. For degrees, convert first: sin(A*pi/180).

Logs and exponentials

Logarithms need a positive input. A real square root needs a non-negative input.

These five functions leave out blank readings among their inputs. Other expressions stay blank when a required input is missing or invalid.

Case matters

Use lowercase pi and e. Column letters take priority: E refers to column E when it exists, so use e or exp(A) for Euler’s number.

In the fit inspector

Custom fit syntax

A custom fit uses x for the independent variable and parameter names such as a and b. For a straight line, enter a*x+b. The operators, trig, roots, logs and rounding syntax above work here too.

See fit types and custom formulas in the manual →

Formula not working?

Check spelling and capitalization, column names and parentheses. Use * for multiplication. A formula column needs a finite real result; division by zero or an out-of-range input leaves the result blank.
