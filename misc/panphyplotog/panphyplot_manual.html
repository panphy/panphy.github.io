Getting started

PanPhyPlotOG is an introduction to plotting experimental measurements. Work with one x-y dataset, add uncertainty bars, and fit a basic model. Start with the steps below, or take the guided tour using practice data.

Enter measurements

Type x and y readings into the table. Use Add Row for more measurements. Tab, Enter and the arrow keys move between cells. Edit the column headings to include names and units, such as Time / s and Distance / m. Headings and the graph title are plain text.

The graph updates as you type. Incomplete and invalid entries stay in the table and are saved, but a fit uses only rows with valid x and y values. Clear Data resets the table after confirmation.

Add uncertainty bars

Uncertainty starts open. Enable Δx or Δy, then choose Absolute or Percentage (%). Type individual uncertainties in the table, or enter a global value and choose Apply to All. Absolute uncertainties must be zero or positive; percentage uncertainties must be positive. Error bars show these uncertainties; they do not weight the fit.

Choose a basic fit

Best Fit starts open. Choose Linear, Quadratic, Cubic, Exponential or Power and press Fit Curve. Linear needs at least two points with distinct x values; quadratic needs three, cubic four, exponential three and the shifted power model four.

The result shows the fitted equation, R² and a fit-status message. A high R² alone does not establish that a physical model is suitable. Changing measurements marks an existing fit as outdated: fit again to update it. Clear Fit removes the fitted line.

Copy the equation as ordinary text or as an image. The equation uses x and y for the horizontal and vertical variables, regardless of the column headings. Very small fitted coefficients use scientific notation. Polynomial results may use a centered, scaled variable u; its definition is included with the equation.

Import, export and copy

Import .csv replaces the current dataset after confirmation. The first two columns supply x and y; named uncertainty columns, such as delta Time or delta Distance (%), are recognized. Other columns are reported as ignored.

Export .csv downloads the current measurements and enabled uncertainties. View Table provides a formatted table to copy into a report or spreadsheet, as an image, or as plain Markdown. The graph camera button downloads a PNG.

Saving your work

This introductory app saves one dataset automatically in this browser. It uses separate storage from PanPhyPlot. Export a CSV to keep a portable copy or transfer the current readings to the full app.

On first use, an original PanPhyPlot save can supply its previously active dataset, headings, drafts, uncertainties, title and basic fit. The complete original save, including other datasets and fit results, stays untouched. PanPhyPlot can import the original datasets, but not their fits. The simplified app never overwrites or deletes it.

Two open PanPhyPlotOG tabs share the introductory save. A tab pauses autosave if another tab changes it, and offers to reload or keep its own version.

Need advanced features?

Check out PanPhyPlot for multiple sheets and series, formula columns, means of repeats, uncertainty propagation, weighted fits, advanced and custom models, LaTeX labels and complete .ppplot project files. Export your readings here with Export .csv, then use File → Import in PanPhyPlot. CSV transfers measurements and uncertainties; fit results and graph settings are not transferred.

Guided practice

The Tour button offers First fit and Uncertainties chapters on tablets and computers. Practice uses its own sample data without changing your saved measurements.
